# YouTube Thumbnail

Branded YouTube thumbnails for livestreams, recaps and Shorts covers: three test concepts, artwork prompts, text and signature layers, placement math and export sizes.

## Installation

```bash
bunx skills add genfeedai/skills --skill youtube-thumbnail video-brand-profile
```

## Usage

```
"Give me three thumbnail concepts for tonight's livestream"
"Brief a recap thumbnail from this final edit"
"Make the Shorts cover for this clip"
"Where does the logo go on a 3840x2160 thumbnail?"
```

## What It Does

- Writes exactly three distinct, honest test hypotheses per video
- Keeps generated artwork separate from exact logos, text and the signature
- Converts the mark's position and size to any export size
- Covers livestream, recap and Short cover modes with their testing limits
- Lists the checks to run at feed size
