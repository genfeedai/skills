# YouTube Description

YouTube descriptions for recaps, livestreams and Shorts: opener, takeaway, accurate chapters, sources and the channel footer.

## Installation

```bash
bunx skills add genfeedai/skills --skill youtube-description video-brand-profile
```

## Usage

```
"Write the description for this recap with chapters"
"Fix these chapter timestamps for the edited video"
"Write the Shorts caption and link the full episode"
```

## What It Does

- Writes a human opener and a specific takeaway
- Builds chapters on the right clock and checks YouTube's chapter rules
- Lists sources and links by what they are
- Adds the channel footer and hashtags from the brand profile
