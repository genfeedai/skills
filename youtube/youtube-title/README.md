# YouTube Title

Truthful YouTube titles for livestreams, recaps, cutdowns and Shorts, written as a pair with the thumbnail.

## Installation

```bash
bunx skills add genfeedai/skills --skill youtube-title video-brand-profile
```

## Usage

```
"Write 5 title options for this Short, keep the best 3"
"Name tonight's livestream from the topic board"
"Pair these titles with the thumbnail text"
```

## What It Does

- Starts from the video's single true answer
- Writes angle-based candidates with length targets per format
- Keeps titles free of bait and unsupported claims
- Pairs each title with its thumbnail so the two do not repeat each other
