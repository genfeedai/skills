# Copywriter

Write and audit conversion-focused copy that adapts to the project brand voice.

## Installation

```bash
bunx skills add genfeedai/skills/copywriter
```

## Usage

```
"Write landing page copy for this new offer"
"Audit this pricing page copy for clarity and conversion"
"Rewrite these CTAs to match our brand voice"
"Improve the microcopy in this onboarding flow"
```

## What It Does

- Discovers project brand voice from docs and existing user-facing copy
- Writes headlines, hero copy, CTAs, value propositions, pricing copy, and microcopy
- Audits copy for consistency, clarity, conversion, and technical quality
- Cuts vague marketing language and replaces it with concrete outcomes
- Adapts tone to the project instead of forcing one generic voice
