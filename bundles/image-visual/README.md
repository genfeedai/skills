# Genfeed Skills - Image Visual Bundle

AI image, video, audio, prompt, cinematography, and visual brand system skills

## Installation

```bash
/plugin marketplace add genfeedai/skills
/plugin install genfeedai-image-visual@genfeedai
```

## Included Skills

- `image-prompt-engineer`
- `cinematic-prompting`
- `prompt-generator`
- `visual-brand-kit`
- `brand-os-architect`
- `media-forge`
