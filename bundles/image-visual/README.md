# Genfeed Skills - Image Visual Bundle

AI image, video, audio, model selection, and visual brand system skills

## Installation

```bash
/plugin marketplace add genfeedai/skills
/plugin install genfeedai-image-visual@genfeedai
```

## Included Skills

- `image-prompt-engineer`
- `visual-brand-kit`
- `model-selector`
- `media-forge`
