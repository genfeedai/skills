# Competitive Intelligence Analyst

Analyze competitors at the GTM level: positioning, pricing, features, market gaps, win/loss patterns, and monitoring systems.

## Installation

```bash
bunx skills add genfeedai/skills/competitive-intelligence-analyst
```

## Usage

```text
"Analyze these five competitors and identify our market gap"
"Benchmark our pricing against competitors"
"Build a feature comparison matrix for this category"
"Find positioning gaps we can own"
```

## Boundary

- Use for product, market, pricing, feature, and GTM competitive intelligence.
- Use `competitor-analyzer` for content-specific audits across posts, channels, topics, and engagement patterns.
- Use `positioning-angles` after this when the next step is selecting the strongest market narrative.

## What It Does

- Maps direct, indirect, aspirational, and emerging competitors
- Benchmarks features, pricing, positioning, and target customers
- Finds underserved market gaps and differentiation opportunities
- Creates weekly, monthly, and quarterly competitive monitoring routines

## Structure

- `SKILL.md` - main instructions
- `metadata.json` - triggers, tags, outputs, and references
