# YouTube Shorts

Turns a long recording into branded YouTube Shorts: clip selection, cutting, burned-in captions, logo and end card, cover, title and caption.

## Installation

```bash
bunx skills add genfeedai/skills --skill youtube-shorts video-brand-profile
```

## Usage

```
"Pick the best 5 Shorts from this livestream transcript"
"Cut and caption this clip for our channel profile"
"Write the title, caption and hashtags for these Shorts"
"Where should captions sit on a 1080x1920 Short?"
```

## What It Does

- Ranks clip candidates for cold-feed discovery
- Cuts one point per Short and keeps the speaker's real claim
- Specifies the 9:16 layout, burned-in captions and safe area
- Adds an end card and an optional corner mark from the brand profile
- Packages the title, caption and hashtags
