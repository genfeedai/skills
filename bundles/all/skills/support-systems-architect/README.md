# Support Systems Architect

Build scalable support and customer success systems that deflect repeated tickets without hurting customer experience.

## Installation

```bash
bunx skills add genfeedai/skills/support-systems-architect
```

## Usage

```text
"Set up a help center for this product"
"Create support templates for our top issues"
"Reduce repeated support tickets without hiring"
"Design a self-service support workflow"
```

## Boundary

- Use when the problem is support infrastructure, docs, ticket deflection, response templates, or support automation.
- Use `constraint-eliminator` when the deeper problem is that customers cannot get the promised result.
- Use `retention-engine` when the main metric is churn, LTV, expansion, or recurring revenue.

## What It Does

- Audits support volume, channels, response times, and repeated issue categories
- Prioritizes FAQs, help docs, onboarding guides, troubleshooting, and status communication
- Creates response templates, routing, SLAs, and escalation rules
- Defines metrics for deflection, satisfaction, resolution time, and retention impact

## Structure

- `SKILL.md` - main instructions
- `metadata.json` - triggers, tags, outputs, and references
