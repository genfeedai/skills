# Expert Architect

Build expert positioning for a founder, creator, consultant, or authority-led brand.

## Installation

```bash
bunx skills add genfeedai/skills/expert-architect
```

## Usage

```text
"Create my origin story for this coaching offer"
"Build expert positioning for my founder brand"
"Find my Big Domino and new opportunity"
"Develop an attractive character for this personal brand"
```

## Boundary

- Use for personal authority and expert-led positioning.
- Use `brand-architect` for company or product brand foundations.
- Use `expert-validator` to score an existing expert narrative before launch.

## What It Does

- Defines attractive character archetype and authority signals
- Builds an epiphany bridge origin story
- Finds the Big Domino belief shift
- Frames the offer as a new opportunity instead of a commodity improvement

## Structure

- `SKILL.md` - main instructions
- `metadata.json` - triggers, tags, outputs, and references
