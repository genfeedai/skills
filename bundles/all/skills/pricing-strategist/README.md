# Pricing Strategist

Create premium and value-based pricing strategy, tier structures, and price-rise plans.

## Installation

```bash
bunx skills add genfeedai/skills/pricing-strategist
```

## Usage

```text
"What should I charge for this service?"
"Create pricing tiers for this SaaS product"
"Help me raise prices without losing the right buyers"
"Compare our price to competitors and reposition value"
```

## Boundary

- Use when the main decision is price, pricing structure, price confidence, or premium positioning.
- Use `offer-architect` when the offer itself is not valuable or clear enough yet.
- Use `competitive-intelligence-analyst` when deeper competitor pricing research is needed.

## What It Does

- Diagnoses underpricing, discount pressure, commodity positioning, and fear of price increases
- Calculates value multiple and price justification
- Designs tiers, anchors, and premium packaging
- Creates rollout plans for price increases and pricing tests

## Structure

- `SKILL.md` - main instructions
- `metadata.json` - triggers, tags, outputs, and references
