# Funnel Validator

Score and improve an existing funnel before driving more traffic through it.

## Installation

```bash
bunx skills add genfeedai/skills/funnel-validator
```

## Usage

```text
"Validate my funnel before I scale ads"
"Why is this landing page sequence not converting?"
"Rate this webinar funnel"
"Audit this application funnel for conversion leaks"
```

## Boundary

- Use when a funnel, landing page sequence, or customer journey already exists.
- Use `funnel-architect` to design the funnel from scratch.
- Use `offer-validator` if the funnel problem appears to be the core offer rather than the sequence.

## What It Does

- Scores hook strength, story connection, offer clarity, value ladder fit, traffic match, and conversion path
- Diagnoses funnel leaks and conversion killers
- Separates traffic-temperature problems from funnel-structure problems
- Prescribes specific fixes before more traffic is added

## Structure

- `SKILL.md` - main instructions
- `metadata.json` - triggers, tags, outputs, and references
- `references/` - supporting reference material loaded only when needed
