# Traffic Validator

Score and improve an existing traffic strategy before scaling acquisition effort.

## Installation

```bash
bunx skills add genfeedai/skills/traffic-validator
```

## Usage

```text
"Validate this 90-day traffic plan"
"Are we choosing paid or organic correctly?"
"Score our Dream 100 and audience ownership plan"
"Why are we getting traffic but not customers?"
```

## Boundary

- Use when a traffic strategy already exists and needs validation or diagnosis.
- Use `traffic-architect` to build the strategy from scratch.
- Use `lead-channel-optimizer` when the task is ROI ranking of actual lead channels.

## What It Does

- Scores Dream 100 clarity, hook strategy, work-in vs buy-in fit, funnel alignment, audience ownership, and conversion path
- Exposes scattered traffic efforts and weak audience strategy
- Connects traffic temperature to funnel readiness
- Prescribes fixes before scaling spend or volume

## Structure

- `SKILL.md` - main instructions
- `metadata.json` - triggers, tags, outputs, and references
- `references/` - supporting reference material loaded only when needed
