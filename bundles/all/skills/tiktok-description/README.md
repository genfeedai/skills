# TikTok Description

Writes the TikTok caption: first line, one supporting fact, specific hashtags and the right disclosures, within the 2,200 character limit.

## Installation

```bash
bunx skills add genfeedai/skills --skill tiktok-description tiktok-title video-brand-profile
```

## Usage

```
"Write the caption for this TikTok"
"Shorten this caption and pick 4 hashtags"
"Do I need a disclosure on this clip?"
```

## What It Does

- Leads with a searchable first line that agrees with the hook and the cover
- Adds the one fact that lets the clip stand alone
- Chooses 3 to 5 specific hashtags
- Flags the disclosures a clip needs
