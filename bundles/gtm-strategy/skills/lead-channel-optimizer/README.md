# Lead Channel Optimizer

Prioritize the lead generation channels that produce the best ROI and can become repeatable acquisition systems.

## Installation

```bash
bunx skills add genfeedai/skills/lead-channel-optimizer
```

## Usage

```text
"Which lead channel should I double down on?"
"Audit these channels by ROI and effort"
"Tell me what marketing activities to stop doing"
"Turn our best lead source into a system"
```

## Boundary

- Use when channel performance data, effort, cost, lead volume, or close rate is available or can be estimated.
- Use `channel-validator` when the main issue is strategic focus or whether the business is spread too thin.
- Use `traffic-architect` for a full audience acquisition plan before channel performance exists.

## What It Does

- Calculates channel ROI from leads, close rate, deal size, time, and direct costs
- Identifies best performers, hidden gems, time sinks, and kill-list activities
- Creates a 10x focus plan for the strongest channel
- Turns the winning channel into a repeatable process with metrics and systemization levels

## Structure

- `SKILL.md` - main instructions
- `metadata.json` - triggers, tags, outputs, and references
