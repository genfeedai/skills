# Positioning Angles

Find differentiated positioning angles and market narratives that make an offer stand out.

## Installation

```bash
bunx skills add genfeedai/skills/positioning-angles
```

## Usage

```text
"Find the strongest angle for this crowded SaaS category"
"We sound like everyone else. Reposition us"
"Name our unique mechanism"
"Create three positioning angles to test"
```

## Boundary

- Use for market angle selection, mechanism naming, and differentiation narrative.
- Use `brand-architect` for brand naming, voice, and broader brand foundations.
- Use `competitive-intelligence-analyst` first when competitor facts, pricing, or feature gaps are unknown.

## What It Does

- Diagnoses market stage and buyer skepticism
- Finds mechanisms competitors skip or cannot credibly claim
- Generates differentiated narratives and angle options
- Scores angles for specificity, believability, differentiation, and testability

## Structure

- `SKILL.md` - main instructions
- `metadata.json` - triggers, tags, outputs, and references
