# Retention Engine

Design retention, activation, ascension, upsell, cross-sell, and LTV systems.

## Installation

```bash
bunx skills add genfeedai/skills/retention-engine
```

## Usage

```text
"Reduce churn for this subscription business"
"Design an ascension ladder after the core offer"
"Create upsells and cross-sells for this product"
"Fix why customers leave after 30 days"
```

## Boundary

- Use after acquisition and purchase when the problem is retention, expansion, or lifetime value.
- Use `constraint-eliminator` when the issue is friction preventing customers from getting the promised result.
- Use `support-systems-architect` when churn is driven by support gaps or repeated help requests.

## What It Does

- Maps the post-purchase journey from immediate confidence through long-term expansion
- Diagnoses churn causes by timing and customer behavior
- Designs ascension ladders, recurring offers, premium tiers, upsells, and cross-sells
- Creates referral, reactivation, and retention metric plans

## Structure

- `SKILL.md` - main instructions
- `metadata.json` - triggers, tags, outputs, and references
