# Traffic Architect

Design audience acquisition and traffic strategy from scratch.

## Installation

```bash
bunx skills add genfeedai/skills/traffic-architect
```

## Usage

```text
"Build a 90-day traffic plan for this offer"
"Create my Dream 100 list structure"
"Decide whether we should work in or buy in"
"Plan how traffic moves into this funnel"
```

## Boundary

- Use for new traffic strategy, Dream 100 planning, organic vs paid path design, and owned audience plans.
- Use `traffic-validator` to score an existing traffic strategy.
- Use `channel-validator` for narrower channel focus and expansion-readiness decisions.

## What It Does

- Maps where the audience already congregates
- Chooses organic work-in vs paid buy-in strategy based on stage and funnel readiness
- Matches traffic temperature to hook, offer, and funnel
- Builds owned audience and follow-up plans

## Structure

- `SKILL.md` - main instructions
- `metadata.json` - triggers, tags, outputs, and references
- `references/` - supporting reference material loaded only when needed
