# Offer Architect

Create high-converting offers, bundles, guarantees, packages, and value stacks from scratch.

## Installation

```bash
bunx skills add genfeedai/skills/offer-architect
```

## Usage

```text
"Create a grand slam offer for this service"
"Package this consulting offer into tiers"
"Build a value stack for this SaaS plan"
"Redesign this weak offer so buyers understand the value"
```

## Boundary

- Use for offer creation and major offer redesign.
- Use `offer-validator` to score an existing offer without rebuilding it from scratch.
- Use `pricing-strategist` when the primary question is price level, premium positioning, or pricing confidence.

## What It Does

- Applies the Value Equation to increase dream outcome and likelihood while reducing delay and effort
- Builds value stacks, bonuses, guarantees, and delivery formats
- Creates bundles, tiers, and named packages
- Outputs ready-to-use offer language and rationale

## Structure

- `SKILL.md` - main instructions
- `metadata.json` - triggers, tags, outputs, and references
