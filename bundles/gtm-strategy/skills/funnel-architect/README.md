# Funnel Architect

Design sales funnels, value ladders, and customer journeys from scratch.

## Installation

```bash
bunx skills add genfeedai/skills/funnel-architect
```

## Usage

```text
"Build a funnel for this coaching offer"
"Create a value ladder for my SaaS product"
"Choose the right funnel type for this $497 course"
"Design the landing page sequence for this launch"
```

## Boundary

- Use for new funnel design and value ladder mapping.
- Use `funnel-validator` to score an existing funnel or diagnose a low-converting sequence.
- Use `offer-architect` before this if the core offer is not clear yet.

## What It Does

- Maps lead magnets, tripwires, core offers, premium offers, and continuity paths
- Selects funnel type based on price point, traffic temperature, and conversion goal
- Designs Hook-Story-Offer for each page or step
- Connects the funnel to traffic and follow-up strategy

## Structure

- `SKILL.md` - main instructions
- `metadata.json` - triggers, tags, outputs, and references
