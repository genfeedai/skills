# Genfeed Skills - Content Loop Bundle

End-to-end Genfeed content loop skills for sensing trends, producing assets, reviewing, posting, measuring, and iterating

## Installation

```bash
/plugin marketplace add genfeedai/skills
/plugin install genfeedai-content-loop@genfeedai
```
