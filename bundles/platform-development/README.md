# Genfeed Skills - Platform Development Bundle

Genfeed workflow, node, connector, posting, onboarding, scope, and MCP integration skills

## Installation

```bash
/plugin marketplace add genfeedai/skills
/plugin install genfeedai-platform-development@genfeedai
```

## Included Skills

- `workflow-creator`
- `node-creator`
- `content-loop-orchestrator`
- `genfeed-connector`
- `social-poster`
- `onboarding`
- `scope-validator`
- `openclaw-integration`
