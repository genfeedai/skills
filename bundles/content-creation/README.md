# Genfeed Skills - Content Creation Bundle

Content creation skills for social, video, newsletters, blogs, launch copy, conversion copy, and new-account warmups

## Installation

```bash
/plugin marketplace add genfeedai/skills
/plugin install genfeedai-content-creation@genfeedai
```

## Included Skills

- `x-content-creator`
- `instagram-content-creator`
- `linkedin-content-creator`
- `youtube-content-creator`
- `newsletter-creator`
- `blog-content-creator`
- `copywriter`
- `launch-copy-creator`
- `x-warmup`
- `instagram-warmup`
- `linkedin-warmup`
- `tiktok-warmup`
- `youtube-warmup`
