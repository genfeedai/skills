# UGC Ad Prompts

A free prompt pack for UGC-style video ads. It covers three formats (selfie ad, talking head, screen demo), three camera modes, reusable identity and pacing blocks, and a pre-flight checklist to run before you render.

## Installation

```bash
bunx skills add genfeedai/skills --skill ugc-ad-prompts
```

## Usage

Ask your agent for a UGC ad prompt and give it the product, the person reference and the line to say:

- "Write a selfie ad prompt for a reusable water bottle, 9:16, 7 seconds."
- "Turn this script into a talking head prompt."
- "Make a screen demo prompt for our checkout flow."

The agent fills the 13-section template, picks a camera mode and runs the checklist. Paste the result into any video model, or into Genfeed.

## What is inside

- The 13 sections and the parameters that fill them
- Fill-in templates for the three formats and one worked example
- Camera modes with framing anchors
- Identity lock and presenter pacing blocks
- Dialogue and timing guidance, and a table of common failures
