# TikTok Title

Writes the headline layer of a TikTok: the on-screen hook, the cover text and the searchable first caption line.

## Installation

```bash
bunx skills add genfeedai/skills --skill tiktok-title video-brand-profile
```

## Usage

```
"Give me a hook and cover text for this clip"
"Three title options for this TikTok, no bait"
"Write the first line of the caption with search words"
```

## What It Does

- Separates hook, cover text and first caption line so they agree but do not repeat
- Keeps lines short, specific and true to the recording
- Follows the brand profile's font, case and spelling
