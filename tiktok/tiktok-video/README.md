# TikTok Video

Turns a long recording or a Short into a branded TikTok video: moment, cut, 9:16 layout, burned-in captions, logo placement, cover and export.

## Installation

```bash
bunx skills add genfeedai/skills --skill tiktok-video video-brand-profile
```

## Usage

```
"Reformat this YouTube Short for TikTok"
"Cut a 30 second TikTok from this livestream clip"
"Where should captions sit on a TikTok?"
```

## What It Does

- Picks and cuts one complete point that opens on the claim
- Lays out 1080 x 1920 with burned-in captions from the brand profile
- Keeps text and faces clear of TikTok interface zones
- Lists what to change when adapting a YouTube Short
