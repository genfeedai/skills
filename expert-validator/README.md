# Expert Validator

Score and improve an existing expert positioning or authority narrative.

## Installation

```bash
bunx skills add genfeedai/skills/expert-validator
```

## Usage

```text
"Validate my expert positioning before I launch"
"Score this origin story and Big Domino"
"Audit whether my personal brand sounds differentiated"
"Tell me why this authority narrative feels weak"
```

## Boundary

- Use when a draft positioning, origin story, or authority narrative already exists.
- Use `expert-architect` to build the expert positioning from scratch.
- Use `positioning-angles` when the work is market angle selection rather than authority narrative scoring.

## What It Does

- Scores Attractive Character, origin story, Big Domino, New Opportunity, authority, and differentiation
- Identifies commodity-zone messaging and weak proof
- Prescribes fixes and routes severe rebuilds back to `expert-architect`
- Keeps the focus on authority-led GTM rather than generic brand strategy

## Structure

- `SKILL.md` - main instructions
- `metadata.json` - triggers, tags, outputs, and references
- `references/` - supporting reference material loaded only when needed
