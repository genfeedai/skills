# Content Factory Operator

Design and operate a repeatable Genfeed AI content factory for agencies, founders, and teams. This skill turns content goals into a managed production system with intake, source research, briefs, creation, review gates, publishing cadence, and analytics loops.

## Installation

```bash
bunx skills add genfeedai/skills/content-factory-operator
```

## Usage

```text
"Build a Genfeed content factory for a B2B SaaS client"
"Design an AI content agency retainer around Genfeed.ai"
"Create a weekly content production system for my founder brand"
"Turn customer call transcripts into a content pipeline"
"Run my content pipeline from trend research to published posts"
"Create a client approval workflow for our AI content factory"
```

## What It Does

- Designs the full content factory: signals, strategy, briefs, production, review, publishing, analytics, and iteration
- Routes work across existing Genfeed skills like `content-strategist`, `content-atomizer`, `content-reviewer`, `workflow-creator`, and platform-specific creators
- Defines source intake systems so outputs are grounded in founder notes, product docs, customer proof, analytics, transcripts, and market signals
- Produces daily operating loops, production queues, approval packets, quality gates, weekly run plans, and monthly reporting templates
- Adds selection, source-integrity, review, approval, and learning gates so daily content improves without relying on operator memory
- Packages Genfeed as a sellable content agency operating system with sprint, retainer, and automation buildout offers
- Works standalone and can hand off Genfeed Studio workflow creation to `workflow-creator`
