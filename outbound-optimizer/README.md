# Outbound Optimizer

Improve outbound strategy, cold email, DMs, personalization, and prospecting systems.

## Installation

```bash
bunx skills add genfeedai/skills/outbound-optimizer
```

## Usage

```text
"Rewrite this cold email to be less spammy"
"Build an outbound sequence for this ICP"
"Diagnose why our reply rate is low"
"Create a prospecting strategy for this offer"
```

## Boundary

- Use for outbound sales and prospecting systems.
- Use `leads-researcher` before this when the target accounts or decision makers are not known.
- Use `email-finder` when the missing piece is contact email discovery.

## What It Does

- Clarifies ICP, pain, trigger, proof, and relevance
- Audits current outreach for length, hook, research, value, CTA, and tone
- Rewrites messages with value-first personalization and low-friction CTAs
- Builds sequences, follow-ups, and volume-quality systems

## Structure

- `SKILL.md` - main instructions
- `metadata.json` - triggers, tags, outputs, and references
