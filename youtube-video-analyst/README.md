# Youtube Video Analyst

Deconstruct YouTube videos to extract viral formulas, hooks, retention mechanics, and reusable content blueprints.

## Installation

```bash
bunx skills add genfeedai/skills/youtube-video-analyst
```

## Usage

```
"Analyze this YouTube transcript and extract the hook pattern"
"Turn this video into a reusable viral blueprint"
"Reverse-engineer the retention mechanics in this video"
"Fetch the transcript for this YouTube URL and deconstruct it"
```

## What It Does

- Analyzes hook architecture, structure, retention mechanics, and emotional engineering
- Extracts reusable templates from successful video transcripts
- Includes a transcript fetch script for YouTube URLs or video IDs
- Maps algorithm signals, CTA architecture, and viral coefficient factors
- Pairs naturally with Genfeed YouTube creation and content atomization skills
