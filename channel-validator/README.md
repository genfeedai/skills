# Channel Validator

Validate whether the business is focused enough on one marketing channel before expanding into more.

## Installation

```bash
bunx skills add genfeedai/skills/channel-validator
```

## Usage

```text
"Validate my channel strategy before I add TikTok"
"Am I spread too thin across these platforms?"
"Should I focus on LinkedIn or cold email first?"
"Score whether we are ready for channel number two"
```

## Boundary

- Use for channel focus, sprawl diagnosis, and expansion readiness.
- Use `lead-channel-optimizer` when you have performance data and need to prioritize the highest-ROI lead source.
- Use `traffic-architect` for designing the full audience acquisition strategy from scratch.

## What It Does

- Scores focus, mastery, avatar clarity, ROI awareness, and expansion readiness
- Identifies channel sprawl and stop-doing candidates
- Forces one avatar, one channel, one offer discipline
- Recommends whether to consolidate, continue mastering, or expand

## Structure

- `SKILL.md` - main instructions
- `metadata.json` - triggers, tags, outputs, and references
- `references/` - supporting reference material loaded only when needed
